# SpeakType agent rules

After a completed SpeakType code change, commit it, publish a new GitHub release with the current DMG, and reinstall the same release to `/Applications/SpeakType.app`.

Do not leave a finished change local unless publishing is blocked. If blocked, report the exact blocker and keep all work recoverable.

Never reset, clean, stash, or discard shared work. Do not publish a DMG that is not signed and notarized.
